Introduction

The Fallout 2 SSL Compiler is a tool for compiling Fallout 2 Scripting Language (SSL) source code into binary INT files that can be used by the Fallout 2 game engine.

This repository contains a modern reimplementation of the original compiler, featuring:

  • Full SSL language support
  • Command-line interface (sslc.exe)
  • VCL-based GUI frontend (FalloutCompiler.exe)
  • Lazarus IDE project compatibility
  • Comprehensive test suite
